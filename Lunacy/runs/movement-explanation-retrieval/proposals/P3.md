# P3 — filing-context and grounded-expansion proposal

## Approach

Keep retrieval and the packet format unchanged. Add one small, deterministic
projection at the existing expansion boundary: affected line refs/source labels,
the supplied current/prior annual periods, and a fixed generic change-language
hint set (`increased`, `decreased`, `driven`, `due to`, `offset`). Do not pass
ticker, filing text outside the packet, or an answer/cause. The expansion prompt
must treat this as target metadata only; a query is admissible only when its
literal query and one contiguous support span still pass the existing first-pass
E-ref and source-text checks.

After exact validation, apply a stable lexical tie-breaker to the already
validated candidates: support spans containing an explicit movement/explanation
cue (`increased`, `decreased`, `driven`, `due to`, `offset`, `resulted from`,
`primarily relate`) outrank spans that only contain static-definition cues
(`includes`, `consists`, `comprises`, `classified`). If any movement candidates
survive, suppress lower-priority static-only expansion candidates and record the
suppression; if none survive, retain static candidates unchanged as fallback.
This is retrieval preference, not a causal assertion or evidence rewrite.

## Exact affected surfaces

- `src/smrik_fund/ingestion/filing_investigation.py`
  - project the bounded expansion context from existing `plan_context`/P&L;
  - accept it in `run_filing_query_expansion`, include only in the model input,

- `prompts/filing_query_expansion.md`: versioned instruction to prefer

- `tests/test_filing_investigation.py`: injected-client context/leakage check;
  movement-over-static selection; static-only fallback; one-pass/exact-ref
  regressions remain covered.

Do not edit `filing.py`, `analytical_scan.py`, `main.py`, adjustment/state code,
or the packet parser.

## Invariants

- Initial plan remains deterministic, bounded, and free of filing-local causes;
  no initial LLM call or new search pass.
- Company-specific expansion vocabulary comes only from an exact first-pass
  excerpt; every accepted phrase keeps its exact support span and E refs.
- At most one expansion call/pass and one final retrieval batch; identity,
  accession, source, offsets, excerpts, and existing validation remain intact.
- Static evidence is retained in the initial packet and remains the fallback
  when no movement candidate is present. No amount, period, sign, allocation,
  residual, plug, adjustment, or model-state write is produced by this change.

## Non-goals

No embeddings/RAG/web search, neighboring-line crawler, repeated/retry loop,
taxonomy or provider/service layer, causality classifier, narrative rewrite, or
changes to Python arithmetic/Financial Investigation.

## Risks / proof

Lexical cues can be noisy (for example, `drive traffic` is not movement); use
only the explicit inflections above and test a static span containing no such
cue. A model could still return a weak neutral phrase, so retain exact
ref/span/source-text gates and expose suppression metadata. Test a packet with
both movement and static candidates, a static-only packet, forbidden company
seed in context/initial queries, and one-call/two-pass bounds with a fake client.
Re-run the existing F1 bridge proof (observed +15.598bn, disclosed +11.3bn,
remainder +4.298bn, plug false), then Findings 2/3: F2 should remain static
fallback when the first packet has no movement phrase; F3 should retain its
`commercial sales`/`higher Copilot advertising expenses` movement evidence.

## Estimated size / complexity

Low: one existing module (roughly 45–75 production lines), one prompt revision,
and roughly 50–80 focused test lines. No new module, schema hierarchy, or
shared retrieval contract.

## Control Block

- Proposal: bounded context + lexical movement-over-static tie-breaker.
- Context: refs/labels/concepts/periods + generic cues only; no causes/ticker.
- Grounding: exact first-pass E refs + contiguous span + filing-text check.
- Preference: movement cues win; static-only candidates are fallback.
- Bounds: one expansion call/pass; one final retrieval batch; max three queries.
- Safety: no arithmetic, allocation, plug, adjustment, or state writes.
- Surfaces: investigation module, expansion prompt, focused tests only.
- F1 proof: +15.598 observed; +11.3 disclosed; +4.298 unresolved; plug false.
- F2: report movement absence when initial packet cannot ground one.
- F3: preserve driven evidence for commercial sales/Copilot advertising.
- Verdict: candidate for synthesis; no source code changed by P3.

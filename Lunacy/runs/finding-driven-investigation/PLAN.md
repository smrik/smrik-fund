# Finding-driven filing investigation — Implementation Hive

## Goal

Add the smallest coherent extension that turns an existing structured Analytical Scan finding into a bounded, evidence-backed explanation from the same MSFT filing while preserving all current financial/lifecycle contracts.

## Authority

1. `AGENTS.md`
2. `USER_NOTES.md`
3. `docs/ai_fund_v1_section_1.md` and `docs/ai_fund_v1_section_2.md`
4. Current repository contracts and tests
5. Lunatic Hive doctrine

## Phases

1. Diversity: three independent read-only Luna proposals after inspecting docs, Analytical Scan, filing retrieval/evidence, structured LLM patterns, CLI, and relevant tests.
2. Synthesis/implementation: one fresh max-effort Luna judges proposals, chooses simplest sound design, implements end-to-end, performs live MSFT proof if credentials permit, and runs required verification.
3. Simplicity/financial adversary: one fresh read-only Luna attacks unnecessary complexity, financial/evidence errors, and analyst usefulness. Any correctness defect routes to a serialized repair step.
4. Repair if required: one bounded Luna repair owner resolves authorized adversary findings and refreshes all invalidated verification/live proof.
5. Parent gate: inspect terminal reports and targeted final diff; run bounded acceptance checks; verdict `PASS` or `DO NOT MERGE`.

## Gates

- Scouts: three durable independent proposals covering approach, surfaces, invariants, non-goals, risks/verification, size.
- Implementation: complete requested behavior; exact provenance; partial explanations/residuals preserved; required checks terminal on final state.
- Adversary: financial correctness and analyst-time-savings judgment, plus simplicity attack.
- Final: no active writer; final diff/check evidence current; no forbidden lifecycle/adjustment changes.

## Verification ownership

- Implementer owns focused tests, relevant regressions, full suite, Ruff, `git diff --check`, live MSFT proof when credentials available, diff review, and production-diff summary.
- Adversary reviews final behavior and evidence; only reruns impacted checks if it edits.
- Parent runs a bounded acceptance sample and independently gates.

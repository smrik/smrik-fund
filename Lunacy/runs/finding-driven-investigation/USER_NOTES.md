- No RAG, embeddings, vector search, autonomous browsing, generic retrieval framework, normalization proposals, forecasts, valuation, or recommendations.
- Normal tests make no live LLM calls.
- If credentials exist, prove on current real MSFT scan without seeding Microsoft-specific answers.
- After live proof, one fresh read-only reviewer assesses financial correctness and analyst time savings.
- Run focused tests, relevant regressions, full suite, Ruff, and `git diff --check`; do not commit or merge.

Final verdict must be `PASS` or `DO NOT MERGE`.

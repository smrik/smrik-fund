## Findings

1. **High — invalid output remains comparable.** `eval_core.py:684-742` stores
   normalized output before critical validation; `:824` then sets `product_valid=False`,
   while `compare_iterations()` (`:354-363`) still compares that output. Evidence:
   offline `msft_segment_growth_mix` is `COMPLETED`, `product_valid=false`, with a
   non-null normalized result in `phases/02-implementation/evidence/offline-all/20260830T101752494309Z/cases/.../case.json`.
   Repair: clear/quarantine normalized output on critical failure and exclude it
   from comparison/scoring.

2. **High — reconciliation is not deterministic at the harness boundary.**
   `eval_workflows.py:569-607` accepts a status allowlist only; it does not recompute
   the bridge from frozen `pnl`/finding or validate reported amounts. Repair: invoke
   the existing reconciliation validator and fail closed on mismatches.

3. **High — ignored analytical inputs can drift undetected.** `source_hashes()`
   (`eval_cases.py:334-342`) and readiness (`:451-529`) omit loaded `input_root`
   P&L (and non-segment reconciliation input). `data/` is ignored (`.gitignore:10`),
   so fingerprints do not catch edits. Repair: freeze/hash every loaded input.

4. **Medium — live-call guard has API bypasses.** Filing executes with an injected
   client when `live_smoke=False` (`eval_workflows.py:684`); smoke allowlist applies
   only when `cases is None` (`eval_core.py:562`). Repair: gate clients/allowlist.

5. **Medium — state-isolation proof is incomplete.**
   `tests/test_eval_harness.py:224-250` checks marker files only; no canonical-file
   snapshot, no history/review-write assertion, and no byte-for-byte first-case
   check after the second case. Runbook claims are stronger than focused proof.

6. **Simplicity — generic core leaks filing semantics.** `eval_core.py:24-37`
   imports private workflow helpers and `:696-746` branches into filing-specific
   validation/re-normalization; module is 955 lines vs P1's 250–350 target. Move
   validation into the filing workflow in a repair pass; no behavior change
   attempted here because it crosses the shared lifecycle boundary.

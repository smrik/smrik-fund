# E2E evaluation harness V1 — Implementation Hive

Goal: implement the smallest repo-native reusable evaluation lifecycle, with filing investigation fully supported and Analytical Scan proving core reuse.

## Phase 1 — independent proposals

Three read-only Luna xhigh scouts independently inspect repo reality and propose: core/CLI/results; filing workflow/judge/failure capture; benchmark inventory/tests/live proof.

## Phase 2 — synthesis and implementation

One fresh Luna max worker judges proposals, selects the simplest sound design, implements all in-scope maintained surfaces, runs required verification, and writes one immutable report.

## Phase 3 — simplicity adversary

One fresh Luna xhigh worker attacks framework creep, domain leakage, unsafe rejected-output handling, benchmark drift, and proof duplication. It may make only bounded behavior-preserving simplifications; correctness findings become repair work.

## Phase 4 — gate

Because this is cross-cutting and adds a shared harness contract, use one fresh read-only Luna xhigh gate scout after the write barrier closes, then parent acceptance gate.

No product repair, no autonomous loop, no commit/merge/push.

# P1 — Reuse-first segment-aware filing investigation proposal

## Recommendation

Extend `filing_investigation.py`'s existing plan -> literal EdgarTools retrieval -> one packet-grounded expansion -> structured investigation -> Python arithmetic flow. No second pipeline, retriever, role, or artifact family.

Resolve every `affected_line_refs` entry before query generation. Keep positional `L##`; add a local `S##` resolver over loaded `load_segment_analytics()` data. Require one deterministic PASS group per ref, one member/metric/label/axis, unique periods, and coherent accession/source identity. Compare against saved scan context; unknown, stale, duplicate, missing, or mismatched refs fail closed. Validate all refs first, so mixed L/S is all-or-nothing.

Thread the optional segment frame through `build_finding_plan_context`, seed construction, observed movement, pair extraction/bridge, investigation, and orchestration. For S refs, copy reported values and saved movement/margin/share/contribution fields; calculate only the existing safe source delta. Preserve accession, source URL/path, fact/context IDs, and units. Seeds use saved segment label + generic metric (`revenue`/`operating income`) + existing movement cues. Descriptions stay fallback; causes enter only through exact evidence and the existing expansion.

Reuse retrieval, packet identity, expansion, narrative grounding, and result validation. Add only a prompt sentence that S describes the segment and cannot assert consolidated causality without filing support. Exact pair arithmetic requires an unambiguous target/period/unit bridge; mixed/multi-driver packets may be `not_computable`/`partial`, never allocated or plugged.

## Non-negotiable invariants

- Every S ref resolves from saved rows, never prose: member/label, metric, periods/values, saved derived context, accession, source identity, units, signs, and missingness survive. No Microsoft names, fuzzy matching, silent regeneration, or invented periods.
- All refs resolve before retrieval. Unknown, stale, duplicate, inconsistent, non-PASS, incomplete/ambiguous, or cross-accession S rows fail closed. Mixed L/S requires every target safe. L mapping and controls remain unchanged.
- Initial retrieval is closed-world/movement-first: saved label/metric/movement vocabulary only; no finding causes, passages, or planner. `planner_call_count=0`; literal budget and three-query cap remain.
- Expansion is at most one pass and may use only exact first-packet text. Evidence IDs, source, accession, locator, exact spans, named entities, signs, periods, and units remain validator-grounded.
- Observed movement, evidence, interpretation, and unresolved remainder stay separate. Quantified drivers require one exact local amount/unit/year span; ambiguity downgrades to unquantified. Unquantified multi-driver evidence gets no allocation.
- Python is the only arithmetic authority. Reconcile only an unambiguous target/period/unit pair; retain explicit unresolved difference and `difference_is_reported_plug=false`. No segment contribution is treated as consolidated causality merely because segment totals reconcile.
- No forecast, valuation, geography, 10-Q/multi-filing, guidance, consensus, adjustment, approved-state, history, or adjusted-P&L write.

## Risks and verification

1. `load_segment_analytics` reassigns refs deterministically. Resolver + exact scan-context equality must catch altered labels/rows; direct APIs without saved context reject non-identity or non-unique S data.
2. MD&A wording may miss generated phrases. Run saved rank 2 and rank 4 against the same filing; capture seeds, rejection reasons, evidence vocabulary/expansion, strongest excerpts, grounding, quantified status, reconciliation, remainder, and usefulness. Honest `no_queries`, `weak`, `partial`, or `not_computable` is acceptable.
3. Run focused filing/segment/scan tests, adjustment/state regressions, full `pytest`, Ruff changed files, and `git diff --check`. Normal tests use fakes/no live LLM or state writes. Fresh proof must match accession and contain no adjustment/history/approved-state output.

# P2 — contract and persistence proposal

## Recommended approach

Extend the existing flow with one plain-data segment-reference resolver. Keep `L##` positional behavior unchanged; resolve `S##` only from the persisted `segment_analytics.csv`, never from scan prose and never by re-extracting the current filing. Validate the persisted `segment_ref` mapping against a deterministic recomputation solely as an integrity check, then aggregate each requested ref into its exact member/label/metric, period/value/derived-metric rows, accession, and source-identity records (`fact_id`, `context_ref`, URL, unit, concept, period metadata).

At the investigation boundary, require every affected ref to resolve. For S refs require one coherent PASS group, one row per saved annual period, stable member/label/metric/axis, complete/coherent source identity, consistent units, and accession equal to both saved scan metadata and the live filing. Require exact `format_analytical_pnl_for_scan(pnl, persisted_segments) == saved_context`; if the segment file is absent, stale, tampered, incomplete, or inconsistent, fail closed. No S refs means the existing consolidated path and artifact shape remain unchanged.

Thread the resolved rows through the current plan/observe/investigate/reconcile calls. Persist a small `reference_resolution`/`resolved_references` extension in the existing investigation JSON (not a new artifact family). Keep L/S observed rows separate; mixed refs never become a synthetic consolidated movement. Reconciliation may compute only one unambiguous target period bridge; otherwise retain existing `not_computable`/partial behavior.

Initial S seeds should be deterministic and generic: `<reported segment label> revenue|operating income` plus the existing movement cues and static fallback. This allows literal MD&A movement hits (for example, segment label + metric + “increased”) without seeding company causes. Reuse the current evidence retrieval, packet-only expansion, exact-support validator, narrative grounding, and no-plug arithmetic.

## Invariants

- Saved `S##` identity is deterministic and collision-safe; persisted ref drift, duplicate period rows, missing periods, unresolved facts, label/metric/axis/unit drift, missing source identity, or accession mismatch fails closed.
- Raw values, signs, missingness, periods, reported basis, accession, and source metadata remain unchanged; derived growth/share/contribution/margin context is deterministic and inspectable.
- `L##` remains compatible; mixed L/S is valid only if every row resolves. Model output may cite only supplied refs.
- Initial retrieval is movement-first and closed-world. Company-specific terms enter only via exact first-pass evidence and one bounded expansion pass.
- Segment and consolidated observations stay distinct; no allocation, residual plug, forecast, adjustment, history, approved-state, or adjusted-P&L write.

## Non-goals

No new taxonomy/ontology, segment-name normalization, filing/10-Q support, geography, retrieval framework/RAG/web/embeddings, new LLM role, repeated loop, forecast/valuation/model action, or source re-generation. Do not “repair” existing v5 quantified/unquantified, exact-evidence, or consolidated safeguards.

## Risks and proof

Main risk is ref renumbering or stale CSV silently mapping a saved S ref to another member. Persisted-vs-recomputed ref equality plus exact full-context equality and accession/identity checks address it. Risk that a segment label appears in both metrics is handled by metric-qualified matching; multi-ref/multi-driver bridges remain partial/not-computable, never allocated.

Use focused injected-client tests for deterministic S resolution, unchanged L, valid mixed refs, missing/duplicate/stale/inconsistent refs, closed-world seeds, movement-over-description, exact expansion, quantified-span safeguards, unquantified multi-driver/no plug, consolidated positive control, and state isolation. Live proof against saved `data/live-segment-enrichment-i1/MSFT/03_output/analysis/analytical_scan_20260828T191302094324Z.json`: rank 2 (revenue concentration, mixed L/S) and rank 4 (segment profitability divergence, mixed L/S). Capture initial queries, evidence-introduced vocabulary, expansion, strongest evidence, driver quantification, unresolved bridge, and analyst usefulness; expect honest partial/weak where evidence cannot bridge.

No new service/class/framework or artifact family; likely 2 production files plus 2 test files (main/filing/scan unchanged).

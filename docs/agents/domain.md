# Domain documents

When exploring the project, read `GLOSSARY.md` if present. If `GLOSSARY-MAP.md`
exists, follow its links for the affected area. Read relevant decisions under
`docs/adr/` and use the project's established terms.

Absent documents are not setup failures. Create a glossary or decision record
only when real project work needs one. Preserve existing domain boundaries and
surface conflicts with earlier decisions before changing the design.
